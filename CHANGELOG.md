# Changelog

All notable changes to **External Link Control by thisismyurl.com** are recorded here. The plugin uses a `x.Yddd` Julian-day version scheme: `x` is the release class (`0` = pre-release, `1` = full), `Y` is the last digit of the year, and `ddd` is the day of year (001-366).

## 0.6123 — 2026-05-03

### Fixed
- Plugin header `Version` (was `0.6112`) and `readme.txt` `Stable tag` (was `1.251231`) now agree on `0.6123`. The mismatch broke `wp plugin status` and would have shipped a wrong-version banner if the plugin were ever auto-pushed to .org.

### Notes
- Release-engineering hygiene only; no behaviour change.
